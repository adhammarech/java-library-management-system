# Java Library Management System

## Academic Project

Developed as part of an Object-Oriented Programming course.

**Final Grade: 100/100**

## Features

* Book and member management
* Librarian and head librarian roles
* Borrowing management
* Category-based book organization
* File-based data persistence
* Exception handling

## OOP Concepts

The project demonstrates:

* Encapsulation
* Inheritance
* Polymorphism
* Object-oriented class design
* Java Collections (`ArrayList`, `HashMap`)

## Technologies

* Java
* Object-Oriented Programming
* Java Collections
* File I/O
* Exception Handling

## Project Structure

The system includes classes for books, members, librarians, borrowing records, categories, database management, and file handling.
